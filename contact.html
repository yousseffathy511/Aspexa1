Frequently Asked Questions

Prompt injection is when an attacker manipulates your AI system through text input to override its safety guidelines, extract confidential information, or execute unauthorized actions. Unlike traditional code injection, prompt injection doesn't require exploiting infrastructure flaws—it exploits the AI model itself. If your system handles sensitive data, processes transactions, or makes decisions, you're at risk. We test for 15+ prompt injection variants specific to your use case.

Standard assessments run 2-4 weeks depending on system complexity. Phase 1 (reconnaissance) is fastest; Phase 4 (exploitation) is most thorough. We provide interim findings so your team can begin remediation while we continue testing. Rush engagements available for critical systems—typically 1-2 weeks.

We conduct adversarial testing in Khaleeji (Gulf Arabic), Egyptian, Levantine, and Maghrebi Arabic—plus Modern Standard Arabic. Most security firms test only in English. If your system serves Arabic-speaking users, dialect-specific vulnerabilities are critical to identify. This is our core differentiator.

Each finding is mapped to OWASP LLM Top 10, MITRE ATLAS, UAE PDPL, and SAMA guidelines. Reports include executive summaries for boards, technical details for engineers, and regulatory documentation for auditors. All mapped to industry standards so there's no translation needed.
